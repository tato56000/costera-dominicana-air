# Costera Dominicana Air Virtual

Sitio web corporativo de Costera Dominicana Air Virtual, aerolínea virtual del Grupo Norjet.

## Publicación en Cloudflare Pages
1. En Cloudflare, abre Workers & Pages y crea una aplicación Pages.
2. Selecciona Connect to Git y conecta el repositorio `tato56000/costera-dominicana-air`.
3. Framework preset: None.
4. Build command: dejar vacío.
5. Build output directory: `/` (raíz del repositorio).
6. Guarda y despliega.

El sitio es estático: no necesita compilación. Los destinos son ilustrativos y la web declara expresamente que se trata de una aerolínea virtual, no comercial.
